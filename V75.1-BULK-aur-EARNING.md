# 🆕 v75.2 — BATCH 2 (aaj ka kaam): saare tools par premium polish

## 1. 📤 BULK MODE v2 — ab **FILE** bhi bhej sakte ho (.xlsx / .csv / .txt)

**Kyun ye zaroori tha:** CA / bank agent / insurance agent ke paas list **file me** hoti hai.
Unse "paste karo" kehna ajeeb lagta hai — wo **file bhejte hain**.

**Ab:**
- User Excel (.xlsx) bheje → bot padhta hai → wahi confirm card → Excel wapas
- CSV (.csv), TXT (.txt), TSV bhi chalta hai
- Purani Windows encoding (cp1252) bhi handle hoti hai
- **Numeric cell ka classic bug fix:** Excel me `800001` ko `800001.0` na bane
- File size limit 8 MB · file handle hone par aage koi handler use nahi chhoota
  (isliye downloader "unknown file" ka double reply nahi karta)

**Ye kyun paisa banata hai:** ab aapka tool **CA ke actual kaam ke flow** me fit ho gaya —
"file bhejo, Excel lo". Yahi cheez ₹1499/month wale plan ko bikwati hai.

## 2. ⚡ CACHE-HIT TAG — "Instant (pehle check kiya tha — 0 API call)"

Pehle cache-hit par bhi `⚡ Response: 1ms` aa jaata tha — user ko samajh hi nahi aata tha
ki ye **taakat** hai ya kuch toota hua.

Ab jab result pehle se yaad tha:
> ⚡ **Instant** — ye pehle check kiya ja chuka tha (0 API call, turant jawab)

Kahan laga: 🏦 **IFSC** · 📮 **Pincode** · 🚗 **Gaadi (RC)**
(bot ke 11 premium cards isi `pcard_foot()` se bante hain — aage jahan chaaho laga sakte ho)

## 3. 🧠 IMEI SMART QUERY — naam ki typo khud sudhaar leta hai

Log device ka naam galat likhte hain → search fail → user sochta hai "tool kaam nahi karta".

| User ne likha | Bot ne samjha |
|---|---|
| `redmi not 12` | **Redmi Note 12** |
| `samsumg a54` | **Samsung a54** |
| `iphon 13` | **iPhone 13** |
| `onepls nord` | **OnePlus nord** |
| `poco x 3` | **POCO X3** |
| `SM A155F` | **SM-A155F** |

**100% offline** (0 API call, kabhi slow nahi karega) · asli naam **waisa hi** rehta hai
(`Redmi Note 10 Pro`, `Mi 11X`, `M2101K6P` — sab safe).

## 4. 🐛 Test ne ek asli bug pakda (aur fix hua)
Bulk file handler happy path par `ApplicationHandlerStop` raise nahi kar raha tha —
matlab **wahi Excel file group-0 ke downloader ko bhi mil jaati** aur user ko **do jawab**
aate (confusion). Ab file handle hote hi handler aage badhna rok deta hai.
