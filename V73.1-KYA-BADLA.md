## ✅ BSEB (Bihar Board) — BAN GAYA (asli, live check)

- Bihar Board ki result website (result.biharboardonline.org) **apni khud ki public API** use karti hai.
- Wo API bot me lag gayi hai — **na captcha, na login**.
- Aapko bas **Roll Code + Roll Number** bhejna hai (admit card par likhe hote hain):

```
11001 100001
```

- Bot **2-3 second** me poora result card de deta hai:
  - 👤 Naam, 👨 Papa ka naam, 🏫 School
  - 🔢 Roll Code / Roll Number, 🆔 Registration No
  - 📚 **Subject-wise marks** (Hindi, Math, Science... har subject ka)
  - 🎯 Total Marks + 🏅 **Result / Division** (First/Second/Third/Pass/Fail)
  - 🏆 Topper hua to "TOPPER!" badge

**Result kab milega:** March-April (Matric/Inter), May-August (compartment).
Baaki mahine bot saaf batata hai: *"is roll ka result abhi live nahi hai"* + kab aayega — crash ya khaali card nahi.

## 🚫 CBSE — sach batana zaroori (aur main gol-mol nahi karunga)

Maine CBSE ka portal **check kiya** (7 Oct 2026):

- CBSE ne apna **purana result portal band** kar diya hai — `cbseresults.nic.in` ab **seedha DigiLocker** par bhej deta hai.
- DigiLocker me **login (mobile OTP)** zaroori hai.
- **Login/password wala kaam bot kabhi nahi karta** — ye aapki suraksha ke liye hai (warna aapke bot par bharosa kaise karega koi?).

✅ Isliye bot me CBSE ka **saaf jaankari card** hai: "CBSE result?" button dabao → poori jaankari:
- DigiLocker app / website par mobile se login karein
- Roll Number + Date of Birth daalein → digital marksheet aa jayegi
- Aur Bihar Board wala result yahin turant milta hai (roll code + roll no bhejo)

## 🛠️ Technical (kaam ki baat)

- Board ka **apna server** use hota hai: `resultapi.biharboardonline.org/result` — jo unki hi website ke peeche chal raha hai.
- **Auto-retry band** rakha hai us par (`retry=False`) — board ke server par aapka bot **halka** rahega, koi load nahi badhega.
- Rate-limit: ek user **5 minute me 10 check** — spam nahi hoga.
- Roll number **kabhi save/log nahi** hota — result laao, card dikhao, bas.
- Server down ho to: *"Bihar Board ka server abhi jawab nahi de raha — 1-2 minute baad Dobara check dabayein."*
- **100% FREE** — premium me nahi joda (PREMIUM_TOOLS 37 hi).
