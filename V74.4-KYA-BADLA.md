## 2) 🔧 Webhook "error" — permanent ilaaj

Aapke Render logs me jo **WARNING** line thi (`WEBHOOK MODE | polling OFF`) — wo error nahi thi, par dikhti darawani thi. Ab:
- **WARNING → INFO**, saaf text: `WEBHOOK MODE ON — polling OFF (Conflict ka koi chance nahi)`.
- **NAYA: Webhook watchdog** — bot har **15 minute** khud check karta hai ki Telegram me webhook theek hai kya. Agar URL badal gaya / koi error aaya / messages atak gaye → **khud dobara set kar deta hai (3 retry ke saath)**. User ko pata bhi nahi chalta. **Ye permanent ilaaj hai.**

# 🔹 v74.6 — CBSE: 🔐 CAPTCHA BRIDGE (captcha aap solve karo, PDF bot dega)

**Sach pehle (aapko pata hona chahiye):** CBSE ne apna purana result portal **band kar diya hai**. `cbseresults.nic.in` ab khud-ba-khud **DigiLocker** par bhej deta hai, jahan **login + mobile OTP** zaroori hai. Purana roll-number form **ab duniya me exist nahi karta** — hum jhoothi LIVE date nahi denge.

**Phir bhi CBSE ka rasta ban gaya — CAPTCHA BRIDGE.** Ye aise kaam karta hai (bilkul waise hi jaise aap khud browser me karte ho, koi jugaad nahi):
1. Aap CBSE card par naya button dabate ho: **`🔎 Result check karo (🔐 captcha)`**
2. Bot official portal ka **asli form** kholta hai aur uska **asli captcha image** aapko Telegram par dikhata hai.
3. **Captcha aap padhte ho** (insaan ki aankh) aur likh dete ho: `AB12C 1234567`
4. Bot wahi captcha + roll number **official server** par bhejta hai.
5. Result aaya → **result card + PDF marksheet** turant neeche ✅
   Galat captcha? → **naya captcha image** aa jaata hai (4 baar tak). Record nahi mila? → saaf likha aata hai.
6. **Bot captcha khud kabhi solve nahi karta** — na OCR, na bypass. Ye pakka rule hai.

**Aur:** jis din CBSE ka form khulega, us din ye button **apne aap kaam karega** — code pehle se taiyar hai.

**Testing:** naya `tests/test_v82.py` — ek **nakli board server** (asli captcha image + hidden fields + POST) par poora flow test: form fetch → captcha image → **galat captcha** → **naya captcha** → **sahi captcha** → result card → **PDF (CBSE header ke saath)** → poori Telegram flow bhi. **40/40 ✅** (koi bypass nahi, sirf user ka captcha).

**Asli CBSE par aaj:** form ki jagah **login-wall** mila → bot saaf bolta hai *"Result abhi nahi mila (portal band login maangta hai)"* — **jhootha result kabhi nahi**.
