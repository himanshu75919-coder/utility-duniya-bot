## ❓ KAUNSE TOOLS KE PAISE LAGTE HAIN, KAUNSE FREE?

| Type | Free? |
|---|---|
| PDF / Photo / Document wale (10-30) | ✅ **100% free** — bot ke andar hi ban jaate hain |
| Kagaz / Sarkari / Guide wale (41-48) | ✅ Free — sirf jaankari likhni hai |
| Download / Media wale (58-60) | ✅ Free |
| AI wale (31-33, 61-67) | ⚠️ Thoda kharcha — AI API ke paise lagte hain (₹100-500/month) |
| Extra APIs (Number info etc.) | ❌ Paid — par bot me pehle se hai |

**Matlab:** list ke **50+ tools bilkul free me ban jaate hain.** Sirf AI wale
tools ke liye thoda paisa lagta hai — aur wo bhi main **free AI** lagakar
bana sakta hoon (thoda dheema chalega, par chalega).
