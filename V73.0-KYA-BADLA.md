## 💬 CHAT X-RAY kya karta hai

Aap **apni** WhatsApp chat ki export file bhejte ho → bot 5-20 second me **poori fun report** banata hai.

**File kaise banayein (1 baar ka kaam):**
WhatsApp → apni chat kholo → **⋮** menu → **Export chat** → **Without media** → wahi `.txt` file bot ko bhej do.
(`.zip` wali export bhi chalegi — bot khud andar se chat nikaal lega.)

## Report me kya-kya milta hai

- 📊 **Total messages · kitne din chali · per day average**
- 👑 **Top chatter** — kisne sabse zyada likha (progress bar ke saath, 5 log tak)
- 🔤 **Top words** — aapki chat ke sabse zyada wale shabd (junk hata ke)
- 😄 **Emoji King** — kisne sabse zyada emoji bheja
- 🤣 **Hasi King** — `haha / lol / 😂` ka champion
- 👍 **OK / Hmm King** — "ok ok... hmm hmm" wala
- 🌅 **Good Morning Champ**
- 🦉 **Raat Ka Jagaadu** — raat 12 se 5 baje kisne sabse zyada likha
- 📏 **Sabse lamba message** — kisne, kitna bada
- 📅 **Sabse busy din + sabse busy ghanta**
- 🖼️ **Media files** kitni bhejin
- Ek **sundar image report** (WhatsApp dark theme me) — jise aap seedha status/group me share kar sakte ho

---

## 🔒 Privacy (sabse zaroori baat)

- File **sirf memory me padhi jati hai** — kahin save nahi hoti, kahin upload nahi hoti.
- Report **sirf aapko** milti hai. Koi doosra user aapki file nahi dekh sakta.
- Isliye ye **100% safe** hai — aapki apni chat, aapka hi report.

## 🛠️ Technical (kaam ka hissa)

- **Android + iPhone + 24-hour + am/pm** — chaaron format support: `12/09/25, 9:41 pm - Rahul:`, `[12/09/25, 9:41:05 PM] Rahul:` — sab parse hote hain.
- `[Photo] <Media omitted>`, "end-to-end encrypted" notice, system messages — **saaf skip** hote hain (ginti me nahi aate).
- `.txt` / `.zip` dono; 12 MB tak; 3 lakh line tak (bada group chat bhi).
- **Koi API nahi, poora offline** — kabhi fail nahi hoga.
- FREE hai — premium me nahi joda, **PREMIUM_TOOLS 37 hi** rahe.
