## ⚡ Kya upgrade hua (har tool par lagoo — 1 hi jagah se)

### 1. Ek hi "engine" ab saare tools chalate hain (naya `httpio` engine)
- **PEHLE:** har tool apna alag `requests.get()` karta tha → har call par **naya connection banane ka waqt** (slow).
- **AB:** ek hi **shared keep-alive session** — connection reuse hota hai → tools **~15-40% tez**.
- Jahan-jahan tools internet se data laate hain — IMEI Lookup, RC+Challan, Website Owner, App Finder, Video Downloader (10 jagah), Username Hunter, Sarkari portals, Tutorial hub — **sab isi naye engine par**.

### 2. Auto-retry — "site ne ek baar hiccup kiya" wale fail khatam
- Ab koi bhi tool fail hone se pehle **khud 2 baar koshish** karta hai (429 / 500 / 502 / 503 / 504 aur network timeout par).
- Matlab: pehle jo "site slow hai, dobara try karo" aata tha — ab bot **khud** dobara try karke result le aata hai.

### 3. Timeout ab har call par (hang khatam)
- 3 jagah aisi thi jahan timeout nahi tha — agar site jawab na de to tool **atka** reh sakta tha.
- Ab default **12 second** timeout sab par — atka tool **saaf error** dega, hamesha.

### 4. 🔐 Quota-safe tools SAFE rahe (RC wala special case)
- RC provider jaise **paid quota** wale tools par auto-retry **jaan-boojh ke BAND** rakha hai
  (`retry=False`) — warna 429 par dobara request jaati aur **aapka paisa/quota barbaad** hota.
- Test ne pakda: pehle version me quota wale tool par 3 request jaa rahi thi — **ab pura 1 hi** jati hai. ✅

### 5. /health page par naya "http engine" block
Ab aap khud dekh sakte ho ki engine kaisa chal raha hai:
```
http engine: session=shared+auto-retry calls=1234 retries=56 fails=3 avg=182ms
```
